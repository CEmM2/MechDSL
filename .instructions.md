## Key Conventions

From `dev/design_docs/07-CONVENTIONS.md`:
- **Index**: lowercase `i,j,k,l` = spatial; uppercase `I,J,K,L` = material; mixed `F_{iI}` = two-point
- **Voigt**: `[xx, yy, zz, xy, xz, yz]` unscaled shears
- **Sign**: tension-positive stress, compression-positive pressure
- **JIT**: 512 lines per `@ti.func`, 2000 per `@ti.kernel`, 5000 ceil
- **Index partition**: physics (range ≤ 6) → `ti.static`; mesh (nodes/elements) → runtime
