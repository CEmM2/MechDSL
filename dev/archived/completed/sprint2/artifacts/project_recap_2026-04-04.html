1 Project Identity
Elevator pitch

A research-grade DSL compiler that takes LaTeX-authored tensor equations and algorithm boxes and emits runnable Taichi GPU-capable finite-element solver code. Built for computational mechanics researchers who write physics in LaTeX and want working code without touching Taichi by hand.

Stage

Pre-alpha. Core IR and Taichi codegen complete. LaTeX frontend blocked on NRPyLaTeX integration. Generated code is structurally correct but has never executed under Taichi JIT.

Key deps

sympy · numpy · opt-einsum · taichi ≥1.7 · nrpylatex (git) · pyyaml

MVP scope

3D Hex8 · Total Lagrangian · SVK elastic + J2 plasticity with power-law hardening · Taichi only · linear solver imported, not reimplemented

4 Design Decision Log
C2 · Apr 3
Quadrature loop: ti.static for Python list indexing
What
The quadrature point loop in emitted kernels uses ti.static(range(N_QP)) rather than a runtime loop.
Why
Shape function tables (dN) are Python lists. Taichi's JIT can only index Python lists at compile-time (ti.static), not at runtime. N_QP=8 for Hex8 — unrolling 8 iterations is well within the 512-line JIT budget and produces correct code.
Alt considered
Restructure dN as a ti.field enabling runtime indexing. Rejected: more complex data model change for identical result at fixed element type.
Impact
Convention docs updated with a "quadrature carve-out." Node loops remain runtime range(N_NODES) per existing convention. Any future element type must define N_QP as a static constant.
H1 · Apr 3
J2 non-convergence: NaN propagation rather than in-kernel raise
What
When radial return fails to converge, dl = NaN is set. NaN propagates into stress → residual norm → the np.isfinite guard in the Newton driver raises RuntimeError.
Why
Raising an exception inside a @ti.func is not supported by Taichi's JIT. NaN propagation is the idiomatic Taichi-safe way to signal constitutive failure upward to Python-level error handling.
Impact
Any code that touches the NaN propagation chain must not swallow exceptions or early-exit before the isfinite check. Removing any link silently hides constitutive failures.
G3 · Apr 3
Dirichlet BC tangent: identity rows, not zero rows
What
Reference solvers set Kv[bc_mask] = v[bc_mask] (identity on fixed DOF rows) rather than zeroing the row.
Why
Zeroing fixed DOF rows makes the global stiffness matrix singular — CG diverges immediately. Identity rows preserve CG-solvability while constraining the displacement increment to zero at fixed DOFs. This is standard penalty-free BC enforcement for iterative solvers.
Impact
Both ref_hex8_elastic.py and ref_hex8_plastic.py updated. Generated code must follow the same pattern. Any future BC implementation must use identity, not zero, on constrained rows.
G1 + G4 · Apr 3
Physics-backed tolerance tightening
What
Rigid body rotation tolerance: 1e-2 * MU → 1e-10. Elastic FD tangent tolerance: 1e-4 → 1e-8. Plastic FD tangent unchanged at 1e-4.
Why
Green-Lagrange strain is rotationally invariant — E=0 at any finite rotation is exact to machine precision, not approximate. The old 1e-2 tolerance was hiding potential bugs. SVK tangent is smooth so O(h²) FD gives 1e-8 at h=1e-4. Plastic tangent has a yield-surface kink (algorithmic non-smoothness) so 1e-4 is the achievable floor.
INFRA · Apr 3
nrpylatex as git dep; local fork clone removed
What
nrpylatex @ git+https://github.com/SOSOVSKI/nrpylatex added to mechdsl-core dependencies. Local nrpylatex_fork/ directory removed.
Why
Local clone inside the uv workspace root broke workspace resolution. Git deps are the correct mechanism for pinned fork dependencies in uv.
Impact
Frontend parsing is now unblocked in principle — the dependency is wired. But NRPyLaTeX integration code has not been written; parser.py remains a stub.

6 Invariants Mental Model Essentials
Key Invariants
  • Three IRs, strictly ordered. LaTeX → ProblemIR → ElementIR → Einsum IR. Symbolic expressions never emit backend code directly. Never bypass an IR layer.
  • IRs are immutable dataclasses validated at construction time. If construction doesn't raise, the object is valid. Mutation after construction is a bug.
  • Voigt is tensorial (unscaled shears). [xx,yy,zz,xy,xz,yz] with factor 1, not 2. 07-CONVENTIONS.md wins over any disagreeing code or comment.
  • Tension-positive stress. Compression-positive pressure: p = -trace(σ)/3. Do not mix sign conventions.
  • JIT budget. Max 512 lines/func, 2000/kernel, 5000 absolute ceiling. Einsum optimizer enforces; exceeding is a hard error not a warning.
  • Physics indices → ti.static; mesh indices → runtime. Quadrature point loops are the exception to this rule (Python list indexing requires static).
Non-Obvious Coupling
  • NaN propagation is intentional. J2 failure sets dl=NaN → stress → residual → np.isfinite guard. Any break in this chain silently swallows constitutive failures.
  • Dirichlet BC tangent must be identity, not zero. Zero rows make stiffness singular. This is encoded in reference solvers; generated code must match.
  • algo2code feeds the Newton driver. The PCG solver is transpiled from a LaTeX algorithm box. AST changes in algo2code affect what gets emitted into the FEM solver.
  • Golden files are source + data. generate_golden.py writes .py.golden alongside .npz. A codegen change breaks source golden even if numbers are unchanged.
  • Supply-chain date lock. exclude-newer = "2026-02-20" blocks packages released after that date. Bump intentionally with audit of the uv.lock diff.
Gotchas
  • Never use break inside ti.static loops. C1 fix: the J2 Newton inner loop had this exact bug. ti.static unrolls at compile time; break is unreachable.
  • Hydrostatic strain never yields in J2. Zero deviatoric stress = no yield. Test strains must be uniaxial or deviatoric to exercise the plastic path.
  • Quadrature loops are static, node loops are runtime. These are different and both matter for JIT correctness.
  • res_norm must be initialized. If max_iter=0, the loop body never runs — res_norm is unbound. Use a sentinel value before the loop.
Naming Conventions
  • Index case = tensor type. Lowercase i,j,k,l = spatial; uppercase I,J,K,L = material; mixed F_{iI} = two-point tensor.
  • emit_*(ctx, bundle) functions write to EmissionContext. Return None. All state is in the context object.
  • ref_hex8_*.py = handwritten NumPy references. *.golden = generated snapshots. Different things — don't conflate them.
  • UnsupportedError must cite the plan phase that adds support. E.g., "Updated Lagrangian planned for Plan B phase B1." Convention, not aesthetics.

The entire taichi_printer.py emitter (the largest module) was implemented and reviewed structurally, but its output has never been fed to ti.init() and run. Correctness is verified only against golden file string comparison. Any Taichi API misuse — wrong dtype, wrong field shape, wrong JIT scope — will only surface at runtime. This is the biggest invisible risk in the codebase.
