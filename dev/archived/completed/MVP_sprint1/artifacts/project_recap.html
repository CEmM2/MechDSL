04 Key Decisions

C2: Quadrature loop ti.static instead of ti.field restructure

N_QP=8 is a fixed element-type constant. Making the quad loop ti.static allows Python list access for GRAD_AT_QUAD/QUAD_WEIGHTS. ~240 unrolled lines fits within the 2000-line kernel budget. Convention docs updated with carve-out.

H1: NaN propagation for J2 non-convergence

Taichi @ti.func cannot return error codes alongside stress tensors. Setting dl=NaN propagates through stress → internal force → residual → res_norm, where the C4b isfinite guard catches it. IEEE 754 guarantees NaN propagation.

G3: Dirichlet BC identity on diagonal

Changed from Kv[bc_mask]=0.0 (singular) to Kv[bc_mask]=v[bc_mask] (identity, preserves SPD). CG convergence is more robust. Applied symmetrically to both reference solvers.

G1+G4: Physics-backed tolerance tightening

G1: Green-Lagrange strain is rotationally invariant → 1e-10 (was 1e-2*MU ~769 MPa). G4: Central FD O(h²) with h=1e-7 → 1e-8 for smooth elastic tangent (was 1e-4). Plastic kept at 1e-4 due to yield surface kinks.

IR discipline: frozen dataclasses with __post_init__

Every IR type validates invariants at construction time. Added to 6 types (J2Material, SVK, HexMesh, QuadratureRule, DirichletBC, NeumannBC). ReturnMappingResult also frozen. HistoryFields intentionally mutable (state management).

06 Mental Model Essentials

Voigt ordering

[xx, yy, zz, xy, xz, yz] with unscaled (tensorial) shears. Not engineering Voigt.

Index convention

Lowercase i,j,k,l = spatial. Uppercase I,J,K,L = material. Mixed F_{iI} = two-point tensor.

IR discipline

Three layers: ProblemIR → ElementIR → EinsumIR. Never bypass. All frozen dataclasses with __post_init__ validation.

JIT budget

512 lines/@ti.func, 2000/@ti.kernel, 5000 ceiling. Physics indices (range ≤ 6) → ti.static. Mesh indices → runtime. Exception: quad points are ti.static when count is element-type constant.

Sign convention

Tension-positive stress, compression-positive pressure (p = -m). f64 only.

Formulation

Total Lagrangian. All quantities in reference configuration. PK2 stress, Green-Lagrange strain.

Error handling pattern

warnings.warn for non-fatal (CG breakdown, FLOPS extraction). raise RuntimeError/ValueError for fatal (non-convergence, invalid params, zero-area face).

Generated code safety

Must be at least as safe as handwritten reference solvers. RuntimeError on non-convergence, NaN guard on residual, CG failure counter (raises after 3), negative dl clamp.

07 Cognitive Debt Hotspots

HIGH Generated code never executed end-to-end

The emitted Taichi solver is verified structurally (ast.parse + pattern matching + golden snapshots) but never actually run. A bug in the generated Newton driver or constitutive function would pass all current tests. Add a @pytest.mark.slow test that imports and runs the emitted module on a 1-element mesh.

MEDIUM FD tangent used everywhere instead of analytical

Both reference solvers and emitted code use finite-difference tangent approximation. The analytical consistent tangent exists in j2_power_law.py (algorithmic_tangent function) but is never wired into code generation. O(n) performance penalty per Newton iteration.

MEDIUM Phase 2 completely absent

The LaTeX frontend (5 tasks: P2.1-P2.5) is blocked on the NRPyLaTeX fork. The pipeline currently starts at ProblemIR construction, not LaTeX input. No fallback parser exists.

LOW Cook's membrane + necking bar benchmarks skipped

Both require infrastructure not yet built: Cook's needs a trapezoidal mesh generator, necking bar needs digitized Simo & Hughes reference data. These are the validation benchmarks that would give confidence in multi-element nonlinear convergence.

LOW Frozen dataclass mutable contents

frozen=True prevents field reassignment but numpy arrays and dicts inside remain mutable. Affects HexMesh, QuadratureRule, DirichletBC, NeumannBC, ArtifactBundle. Fix: array.flags.writeable = False in factory functions.
